# Recorridos de campo

Este repositorio fue la primera casa de las guías de campo para celular. Ahora viven en dos familias, cada una con su repositorio:

- **Recorridos SOMEXA**: https://hectortecumshe-ai.github.io/recorridos-somexa/ (repositorio `recorridos-somexa`)
- **Viajes de estudio propedéutico**: https://hectortecumshe-ai.github.io/viajes-de-estudio-propedeutico/ (repositorio `viajes-de-estudio-propedeutico`)

Las carpetas `somexa-2026/` y `propedeutico-21-2026/` solo redirigen a la nueva dirección. La versión 1.0.0 del Recorrido SOMEXA 2026
(DOI 10.5281/zenodo.23433293) está en la etiqueta `v1.0.0` de este repositorio; la versión 1.1.0 (DOI 10.5281/zenodo.23642326) vive en `recorridos-somexa`.
